B787 CDU PREFLIGHT (PF)

FCOM NP.21.2-5 · page flow
Download 1-page PDF handout

1 - Initial Data

  • IDENT: verify MODEL; verify ENG RATING; cycle the active NAV database to erase prior pilot-entered data; verify NAV database ACTIVE date range current.
  • POS INIT: verify time; if SET INERTIAL POS line is boxed, enter present position (most accurate lat/long).

2 - Nav Data

  • RTE: FLT NO exactly as on Dispatch Release, ROUTE REQUEST; when ROUTE UPLINK appears, LOAD; verify/enter ORIGIN and DEST; verify/enter route; ACTIVATE and execute RTE 1.
  • DEPARTURES: select runway or HUD TAKEOFF; select departure routing; execute.
  • POS REF 2: verify correct RNP for departure as needed.
  • NAV RADIO: set up raw-data navaids for the engine-out (EO) departure / escape routing; tune as needed.
  • ARRIVALS: select runway; select arrival routing; execute. Do not load an instrument approach before departure.
  • FIX INFO (ETOPS): enter all ETPs from the Dispatch Release / Flight Plan; 410 NM circle around the adequate airport defining the EEP.

3 - Perf Data

  • PERF INIT: if PERF INIT DATA available, ACCEPT; verify/enter ZFW; verify FUEL on CDU, Dispatch Release, and EICAS agree; verify fuel sufficient; verify/enter RESERVES (hold plus alternate); verify/enter CRZ ALT; verify/enter COST INDEX; enter STEP SIZE 0.

4 - Wind Data

  • FMC COMM: WIND, LOAD and execute; DES FORECAST, LOAD; CLB FORECAST, LOAD.

5 - Legs Verification

  • LEGS: crosscheck waypoints, speeds, altitudes, sequences against the flight plan.
  • NAV DATA: ORCN/ETOPS, PF and PM independently verify lat/long of unnamed oceanic waypoints. ARINC 424 check: LEGS to scratchpad, INIT REF, INDEX, NAV DATA, paste into IDENT, compare lat/long to flight plan/clearance.

6 - Register

  • OPS CONTROL (FCOM: COMPANY - FLIGHT INIT): verify/enter FLIGHT NUMBER; SCHEDULED DATE (numeric day) from Dispatch Release; ORIGIN/DESTINATION stations; CAPT, F/O, R/O employee numbers. Complete before requesting the preliminary TPR.
  • ATC LOGIN (ATC LOGON/STATUS): LOGON TO, FLIGHT NUMBER, ORIGIN/DESTINATION, SEND. KSEA / CONUS Data Comm: LOGON TO = KUSA. PHNL: use the departure clearance (PDC), not a CPDLC logon.

Bookends and gates

  • D-ATIS (press COMM): FLIGHT INFORMATION > ATIS REQUEST; verify the D-ATIS altimeter numeric value equals the alpha value (FCOM SP.5.1).
  • REQUEST: preliminary performance via datalink (needed for AeroData final perf; do not load into the FMS; need not print).
  • Initial Data and Nav Data complete before the flight instrument check; Perf Data complete before the Before Start Checklist.
